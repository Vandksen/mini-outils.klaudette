ACDCompta (ACD Groupe)

Mini-outils est conçu pour ACDCompta, le logiciel de comptabilité d'ACD Groupe utilisé en cabinet d'expertise comptable. Les écritures générées sont copiées d'un clic, puis collées dans ACDCompta : les colonnes arrivent dans l'ordre attendu, sans retouche.

Cinq outils produisent des écritures comptables à coller, dont un avec sa note de calcul ; le sixième produit une note seule :

Le format des écritures

Chaque écriture tient sur une ligne. Les colonnes sont séparées par des tabulations, comme lors d'un copier-coller depuis un tableur.

Format à 6 colonnes : date, pièce, compte, libellé, débit, crédit.

Format à 8 colonnes : date, pièce, compte, libellé, deux colonnes techniques, débit, crédit. Les deux colonnes techniques sont vides pour les extournes ; pour l'import banque, la seconde contient « FAUX ».

Dans les deux formats, la date est écrite JJ/MM/AAAA et les montants avec une virgule décimale, sans séparateur de milliers, par exemple 1200,00.

Autres logiciels comptables

Mini-outils n'a été utilisé qu'avec ACDCompta. Un autre logiciel comptable peut recevoir ces écritures s'il accepte le collage de lignes dans cet ordre de colonnes ; cela n'a pas été vérifié.

Les tableurs (Excel, Google Sheets, LibreOffice Calc) acceptent ce collage : chaque valeur arrive dans sa cellule. Vous pouvez donc passer par un tableur pour réordonner les colonnes avant un import dans un autre logiciel.

Vous utilisez un autre logiciel et souhaitez un format adapté ? Les coordonnées de contact figurent dans les mentions légales.

Indépendance

Mini-outils est un projet indépendant, sans lien avec ACD Groupe ni avec un autre éditeur de logiciel comptable. Les noms de logiciels sont cités pour décrire la compatibilité.
